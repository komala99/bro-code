# Java Programming – Bro Code Course

This repository contains my Java programming practice and implementations based on the Bro Code Java Full Course (12 Hours).

The objective is to develop a strong foundation in Java programming through hands-on exercises, concept-based implementations, and consistent coding practice.

**Technology Stack**
- Language: Java
- JDK: Java 21
- IDE: IntelliJ IDEA
- Version Control: Git and GitHub

**Topics Covered**
- Java Fundamentals
- Variables and Data Types
- User Input
- Operators and Expressions
- Conditional Statements
- Loops
- Methods
- Arrays
- Strings
- Object-Oriented Programming
- Collections Framework

**Repository Structure**

```text
bro-code/
└── src/
    ├── Basics/
    ├── Variables/
    ├── ScannerClass/
    └── ArithmeticOperators/
```

Each topic is organized into separate packages containing individual Java programs for practice and implementation.

**Learning Approach**

- Understand fundamental programming concepts.
- Implement programs independently.
- Practise problem-solving and debugging.
- Maintain organized, readable code.
- Track learning progress through Git commits.

This repository is part of my continuous journey towards becoming a Software Development Engineer (SDE).
